# Social Media Data Analysis

## Project Overview
Project analyzing fictionalized social media data in order to glean marketing insights.

## Objective
The dataset includes insights about the performance of 10,000 posts on various platforms. My job was to see wath type of content performs the best on which platforms and give insights to the marketing department on future strategy.

## Data source

[Social Media Performance & Engagement Data](www.kaggle.com/datasets/svthejaswini/social-media-performance-and-engagement-data?resource=download) Accessed via Kaggle on 2026.04.19

## Tools used

The Python libraries used in this project were:
- pandas, numpy, os for data analysis
- matplotlib.pyplot, scipy, seaborn for visualizations
